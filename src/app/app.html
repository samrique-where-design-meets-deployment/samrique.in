Under the hood

Architecture
and data

The app is organized into screens (lib/views), GetX controllers (lib/controller), data models (lib/models), and API/export services (lib/services).

Account, transaction, category, and statistics data are loaded from a REST API. Theme selection and custom categories use shared_preferences; transaction data is not stored locally by this Flutter client.

Connect your backend

Set the API base URL at build or run time with API_BASE_URL.

--dart-define=API_BASE_URL=<url>

Without a value, Android emulator builds use http://10.0.2.2:3000/api; other platforms use http://localhost:3000/api. A compatible backend must be running and reachable.

Android emulator on Windows

Run start_pixel_7_pro_emulator.cmd once to install the background monitor that starts with Windows, launches the Pixel 7 Pro emulator when needed, and keeps its window on the primary display. Select the emulator in VS Code to run the app. To disable automatic startup, remove Keep Pixel 7 Pro Visible.lnk from your Windows Startup folder.

Configuration
